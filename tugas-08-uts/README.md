# Tugas 8 (Pekan 8) — UTS

Pekan ke-8 adalah **Ujian Tengah Semester**, bukan tugas take-home berbasis repositori.

Materi yang diujikan mencakup seluruh **Bagian 1: Sistem Terdistribusi** (Tugas 1–7):
- Pitfall sistem terdistribusi
- Architectural style (Layered, SOA, Pub-Sub)
- Threading, Virtualization, Container
- RPC & Message-Oriented Middleware
- Physical/Logical Clock, Election Algorithm
- Naming (Flat, Structured, DHT)
- Data-Centric & Client-Centric Consistency

Format, jadwal, dan teknis ujian mengikuti pengumuman dosen di luar repositori ini (mis. LMS kampus). Tidak ada berkas yang perlu dikumpulkan di folder ini.
